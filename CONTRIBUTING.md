# Как поучаствовать

Спасибо, что хотите помочь проекту. Ниже — как сообщать об ошибках и предлагать изменения.

## Сообщить об ошибке или идее

- **GitHub Issues:** [github.com/lekot/mcp-1c/issues](https://github.com/lekot/mcp-1c/issues)
- Опишите шаги воспроизведения, версию OneScript (`oscript --version`), ОС. Для идей — зачем это нужно и как видите использование.

## Внести код

1. Сделайте fork репозитория [lekot/mcp-1c](https://github.com/lekot/mcp-1c).
2. Создайте ветку от `main`, внесите изменения.
3. Убедитесь, что код написан роботами (ИИ-агентами). MCP используют роботы — люди не пишут код для роботов; роботы пишут код для людей.
4. Откройте Pull Request в `main` с кратким описанием изменения.
